# KEYBOARDS-L2-01 — второй уровень клавишных

## Основание классификации

«Клавишные» — пользовательское семейство по исполнительскому интерфейсу, а не единый органологический класс.

Поэтому L2 строится по устойчивым инструментальным мирам и допускает двойную принадлежность.

## Двойная принадлежность

- клавесин: клавишные + исторические;
- историческое фортепиано: клавишные + исторические;
- челеста: клавишные + оркестровые / ударная органология;
- Hammond и родственные: органы + электромеханические / электронные;
- MIDI-клавиатура: клавишные + электронная инфраструктура;
- синтезатор: клавишные, только если клавиатура является исполнительским интерфейсом; синтез как технология шире клавишной ветви;
- баян/аккордеон могут иметь клавиатуру, но их основная родина остаётся в свободно-язычковой меховой семье.
