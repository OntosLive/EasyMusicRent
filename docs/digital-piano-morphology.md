# Предметная морфология: цифровое пианино

Цифровое пианино наследует общий инвариант фонда, но имеет собственную предметную геометрию.

## Главный инвариант

> Цифровое пианино выбирают не по количеству функций. Его выбирают по тому, насколько хорошо оно сохраняет фортепианную практику в конкретных домашних, учебных или сценических условиях.

## Собственные оси

### 1. Клавиатура
- 88 клавиш;
- полноразмерная клавиатура;
- взвешенная механика;
- молоточковая механика;
- градация веса клавиш;
- повтор ноты;
- глубина и длина клавиши;
- ощущение чёрных клавиш;
- поверхность клавиш.

### 2. Педали
- одна педаль;
- тройной педальный блок;
- полупедаль;
- устойчивость педального блока.

### 3. Форм-фактор
- переносное;
- корпусное;
- сценическое;
- компактное;
- для постоянного места дома;
- для частых переездов.

### 4. Акустическая среда
- квартира;
- наушники;
- ночные занятия;
- встроенная акустика;
- внешнее усиление;
- запись;
- сцена.

### 5. Учебная траектория
- ребёнок;
- музыкальная школа;
- взрослый начинающий;
- возвращение к фортепиано;
- училище;
- консерватория;
- профессиональная практика.

### 6. Технологический слой
- USB/MIDI;
- Bluetooth;
- запись;
- приложение;
- подключение к компьютеру;
- линейный выход;
- два выхода на наушники.

### 7. Временной режим
- месяц;
- учебный год;
- на время ремонта акустического пианино;
- на время переезда;
- перед покупкой;
- для временного жилья;
- для проекта.

## Специфический закон

> В цифровом пианино эргономика клавиатуры важнее списка тембров.

## Компиляция

человек → фортепианная задача → клавиатура → педали → среда → форм-фактор → срок → конкретная модель
