# Второй проход по модельным страницам

После генерации страницы по бренду, серии или модели обязателен второй проход через канон.

Первый проход создаёт поисковый адрес: бренд → серия → модель → поколение.

Второй проход возвращает человека:
1. Кто пришёл на страницу?
2. Что происходит у него сейчас?
3. Почему именно эта модель оказалась в поле внимания?
4. Какое напряжение решает временный доступ?
5. Что остаётся узнать перед контактом?
6. Если текст без потерь переносится на соседнюю модель, сцена не раскрыта.

> Модель — адрес входа. Сцена — причина существования страницы.

Техническая классификация строит карту. Второй проход превращает карту в живые адреса.
