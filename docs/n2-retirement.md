# Отказ от отдельного N.2

Публичная предметная архитектура:

N.0 = /<slug>/ — поисковый вход / доступ  
N.1 = /details/<slug>/ — знание + дочерняя навигация  
далее = дочерние сущности следующего уровня

Содержимое прежних L1-страниц /<slug>/karta/ встроено в соответствующие N.1.

Старые /karta/ пока не удаляются и не перенаправляются автоматически. Они остаются техническими адресами до отдельного решения об их судьбе.
