# Эталонная поисковая морфология: контрабас

Первый эталонный организм для генератора поисковых гипотез.

Файлы:

- `data/morphology/contrabass.json` — предметная морфология;
- `tools/morphology_generate.py` — общий генератор;
- `data/search_hypotheses_contrabass.csv` — текущий корпус гипотез.

Принцип:

> Не перемножать слова. Выводить осмысленные сцены из реальной способности.

Текущий корпус содержит 90 уникальных гипотез.

Следующий слой:

1. измерить гипотезы;
2. сохранить нулевые и низкочастотные;
3. отметить живые формулировки;
4. собрать паспорта сцен;
5. опубликовать адреса независимо от того, была ли частотность условием их появления.
