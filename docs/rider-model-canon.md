# Канон модельного слоя: Rider Core и Legendary Core

Статус: действующий принцип наполнения модельных страниц ONTOS.RENT.

## 1. Приоритет моделей

Модельный слой развивается не по полноте каталогов производителей, а по реальному языку музыкантов, технических райдеров, бэклайна и профессиональной истории.

Порядок приоритета:

1. **Rider Core** — модели и серии, которые регулярно фигурируют в профессиональном прокате и райдерах как самостоятельные позиции.
2. **Legendary Core** — исторические модели, имя которых само стало музыкальным референсом и устойчивым поисковым объектом.
3. **Current Pro** — актуальные профессиональные модели, которые являются естественными заменами, современными стандартами или быстро становятся backline-позициями.
4. **Specialist Model** — узкая профессиональная модель с самостоятельной исполнительской функцией.
5. Остальной ассортимент производителя не получает страницу только ради полноты линейки.

## 2. Источники

Для Rider Core желательно иметь одновременно:

- свидетельство реального rental / backline inventory;
- первичный источник производителя для конструкции и точных характеристик.

Для Legendary Core:

- первичный исторический источник производителя, музея или архива;
- при наличии — подтверждение современной rental-практики.

Факт присутствия модели на публичной странице не означает собственного наличия ONTOS.RENT.

## 3. Что должна отвечать модельная страница

Модельная страница раскрывает:

- почему модель запрашивают по имени;
- какое исполнительское различие сохраняется при точном совпадении;
- какие параметры райдера всё равно нужно уточнить;
- что считается допустимым substitute;
- какие принадлежности и конфигурация являются частью рабочей позиции;
- какие свойства относятся ко всей модели, а какие — только к конкретному экземпляру.

Запрещено писать страницу как перечень характеристик без сцены.

## 4. Substitute

> **Профессионально хороший инструмент не является автоматическим substitute для указанной модели.**

Если райдер называет модель или серию, замена согласуется явно.

Особенно это важно для:

- разной клавиатурной версии одной workstation;
- разных схем звукоснимателей гитары;
- Precision / Jazz / StingRay;
- Stratocaster / Telecaster / Les Paul / ES-335;
- размеров и конфигураций барабанного shell pack;
- F/B♭ и wrap-систем валторны;
- типа тромбона и вентилей;
- строя тубы;
- vintage hardware и современных reissue / emulation;
- настоящего Hammond + Leslie и цифровой эмуляции.

## 5. Серия и конфигурация

Некоторые райдерные названия являются сериями, а не одной фиксированной моделью.

Примеры:

- DW Collector's Series;
- Gretsch USA Custom;
- Yamaha Recording Custom;
- Zildjian A / K Series.

Для них модельная страница обязана продолжить запрос до конкретной конфигурации:

**серия → размеры / состав → принадлежности → подготовка → сцена.**

## 6. Старые модели сохраняются

Окончание серийного производства не удаляет модель из модельной карты, если она продолжает жить в:

- райдерах;
- профессиональном прокате;
- студиях;
- исполнительской культуре;
- поисковом языке музыкантов.

Поэтому Nord Stage 3, Yamaha Motif XF8, Korg Kronos 2, Roland JUNO-106, Selmer Mark VI и другие старые стандарты имеют право на самостоятельный адрес.

## 7. Где модельная логика неприменима

Нельзя насильно переносить промышленную модельную логику на категории, где главными координатами являются:

- мастер / школа изготовления;
- возраст и происхождение;
- размер;
- мензура;
- индивидуальная геометрия;
- состояние конкретного экземпляра.

Это особенно важно для акустических скрипок, альтов, виолончелей, контрабасов и многих исторических / традиционных инструментов.

Там вместо фиктивного «Rider Model Core» развиваются страницы конкретных мастеров, школ, размеров, исполнительских конфигураций и экземпляров, когда для этого есть реальное основание.

## 8. Формула

> **Модель получает адрес, когда её имя уже несёт исполнительскую информацию.**

И затем:

**имя из райдера → точная конфигурация → конкретный экземпляр → проверка substitute → рабочий комплект → музыкальная сцена.**


## 9. Пять типов модельной сущности

Слово «модель» в разных инструментальных мирах означает разные вещи. До публикации нужно определить тип сущности.

### A. Exact Model

Одна определённая промышленная модель с устойчивой исполнительской функцией.

Примеры:

- Yamaha CP88;
- Nord Stage 3 88;
- Buffet R13;
- Bach 42BO;
- Fender ’65 Twin Reverb;
- Yamaha YM-6100.

Формула:

**точная модель → версия / год → конкретный экземпляр → комплект → сцена.**

### B. Series + Configuration

Название профессиональной серии, внутри которой райдер обязан продолжиться размерами или составом.

Примеры:

- DW Collector’s Series;
- Yamaha Recording Custom;
- Yamaha Absolute Hybrid Maple;
- Gretsch USA Custom;
- Zildjian A / K;
- Paiste 2002;
- Sabian HHX.

Формула:

**серия → точные размеры / подмодели → комплект → подготовка.**

### C. Legendary Lineage

Имя, которое пережило отдельный год выпуска и стало самостоятельным музыкальным референсом.

Примеры:

- Gibson F-5;
- Rhodes Mark I;
- Fender Precision / Jazz Bass;
- Ampeg SVT;
- Roland TR-808;
- Minimoog Model D;
- Yamaha DX7.

Здесь особенно важно различать:

- оригинал;
- позднюю серийную версию;
- reissue;
- аппаратную recreation;
- software/emulation.

### D. System / Rig

Райдерная единица состоит из нескольких предметов и теряет смысл при разрыве цепочки.

Примеры:

- Hammond B3 + Leslie 122;
- Ampeg SVT-CL + SVT-810E;
- Marshall JCM800 + 1960A/B;
- guitar + amp + cabinet, когда артист требует весь тракт.

Формула:

**узлы → совместимость → коммутация → stage setup → музыкальная функция.**

### E. Maker / School / Specimen

Серийная модель не является главной координатой.

Прежде всего:

- акустические скрипки;
- альты;
- виолончели;
- контрабасы;
- многие исторические инструменты;
- часть традиционных инструментов.

Здесь модельный слой заменяется системой:

**мастер / школа / эпоха → размер / мензура / конструкция → конкретный экземпляр → состояние → исполнитель.**

## 10. Семейства фонда и тип главного профессионального идентификатора

| Семейство | Главный идентификатор профессионального запроса |
| --- | --- |
| Клавишные | Exact Model / Legendary Lineage / System |
| Смычковые | Maker / School / Specimen; Exact Model для электрических |
| Гитары | Exact Model / Legendary Lineage |
| Щипковые струнные | Model там, где имя устойчиво; иначе maker / traditional type |
| Арфы и лиры | Exact Model + конкретный экземпляр |
| Духовые | Exact Model + система + конкретный экземпляр |
| Ударные и перкуссия | Series + Configuration; Exact Model для mallet / timpani / snare |
| Баян, аккордеон и гармонь | Exact Model / индивидуальная конфигурация / система клавиатур |
| Электронные инструменты | Exact Model / Legendary Lineage |
| Народные и традиционные | Maker / regional school / tuning / specimen |
| Исторические | Maker / reconstruction school / pitch standard / specimen |
| Редкие и экспериментальные | Exact device или уникальная конструкция |
| Усилители и бэклайн | Exact Model / Rig / cabinet configuration |

## 11. Правило полноты

Исчерпывающий модельный слой не равен бесконечному списку SKU.

Для каждого семейства сначала закрываются:

1. модели, которые музыканты реально называют в райдерах;
2. модели, которые прокатчики держат как отдельные позиции;
3. исторические модели, имя которых само несёт исполнительскую информацию;
4. актуальные профессиональные replacements;
5. специализированные модели, у которых нет содержательно эквивалентной общей страницы.

После этого дальнейшая детализация идёт только при появлении нового исполнительского различия, реального rental evidence или устойчивого поискового языка.

## 12. Закон исторической живучести

> **Прокат является не только логистикой настоящего, но и оперативным архивом музыкальной технологии.**

Снятая с производства модель остаётся активной сущностью фонда, пока:

- существует в профессиональных парках;
- указана в действующих райдерах;
- на ней сохранены концертные программы;
- её физический интерфейс остаётся необходим исполнителю;
- её название продолжает обозначать отдельный музыкальный результат.

Это объясняет присутствие рядом в одном фонде новых CP88 / RD-2000 EX и старых Motif XF8 / Kronos 2 / Rhodes / Wurlitzer / DX7 / D-50.
