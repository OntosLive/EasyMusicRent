# Историко-редкая волна 01: 64 человеческие сцены, корпус 1660 тем

Дата: 6 октября 2026 года.

## Ритм работы

Волна собрана пакетно:

**предметная волна → лёгкая проверка → один переход в main → один полный release-контур.**

Исходная точка: **1596 тем**.  
Целевой корпус после волны: **1660 тем**.

## Что сознательно не делалось

- «исторический» не трактовался как единая стилистическая категория без эпохи и конструкции;
- историческая конфигурация не объявлялась автоматически лучше современной;
- реконструкция не выводилась из одного внешнего сходства;
- редкие инструменты не превращались в SEO-каталог названий без исполнительской задачи;
- экспериментальные устройства описывались через физический интерфейс и музыкальную функцию;
- не перемножались города, сроки и синонимы;
- наличие страницы не трактуется как наличие конкретного экземпляра фонда.

## Предварительная проверка

До перевода в `main`:

- четыре новых JSON-файла разбираются;
- количество: 16 + 16 + 16 + 16 = 64;
- все 64 slug уникальны внутри волны;
- у каждой записи есть предметный родитель;
- у каждой записи есть `search_title`, `editorial_title`, `description`, три смысловых блока и итоговый вопрос;
- пустых элементов в `sources` нет.

Полный граф ссылок, исторические пересечения и весь корпус проверяет релизный компилятор после публикации волны.

## Содержательный результат

Историческая ветвь теперь лучше выражает собственную грамматику:

**эпоха / источник → конкретная конструкция → строй / механика → исполнительский переход → ансамблевая или проектная функция → временный доступ.**

Редкая ветвь раскрывает другой маршрут:

**замысел → физический жест → механизм звука / управления → проба → проект → возврат в фонд.**

Это особенно соответствует концепции ONTOS.RENT: редкий инструмент чаще нужен не как собственность, а как временный доступ к одной невозможной без него музыкальной функции.
