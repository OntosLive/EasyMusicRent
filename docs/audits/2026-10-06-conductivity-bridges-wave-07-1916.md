## Форматы урока

Страницы «урок дома», «онлайн-урок», «мастер-класс», «урок в другом городе», «летняя академия» и другие теперь ведут к конкретным продолжениям:

- домашний урок → первые занятия дома / практика между уроками;
- онлайн-урок → дистанционное цифровое пианино / электронные барабаны;
- мастер-класс → консультация профессора / инструмент в другом городе;
- групповой урок → Orff-группа / ансамблевый урок;
- урок с концертмейстером → пианино для аккомпанемента / камерный класс;
- выездная школа ↔ летняя академия ↔ учебный сбор;
- два преподавателя → сравнение вариантов / параметры;
- смена преподавателя → выбор по функции / временный инструмент.

## Учебные вехи

Экзамен, конкурс, прослушивание и поступление больше не заканчиваются общей рекомендацией.

Они ведут к:

- технической работе;
- динамике;
- звуку;
- step-up;
- смене размера;
- ансамблевой функции;
- диапазону;
- интонации;
- ритму;
- выносливости.

Смысл: **веха разворачивается в то исполнительское различение, которое нужно проверить до самой вехи.**

## Отклик и механика

Технические симптомы теперь соединены с конкретными соседними маршрутами:

- тихая нота не начинается → амбушюр / работа над звуком;
- шумная атака → студийный шум / работа над звуком;
- неодинаковые клавиши → механика / повторная нота;
- медленный клапан → механика / ритм;
- тугая кулиса → тромбон перед покупкой / квартвентиль;
- заедающий пистон → труба перед покупкой / механика;
- педаль-кнопка → педагогическое замечание / промежуточное положение;
- жёсткие струны → усилие / усталость левой руки;
- неверный rebound → динамика электронных барабанов / rudiments;
- рывки меха → аккордеон / баян и работа мехом;
- плавающий строй → интонация / другой строй;
- шум механики в записи → студийный шум / DI.

## Диапазон и конфигурация

Страницы диапазонных ограничений теперь ведут к реальным предметным решениям:

- не хватает низа → дополнительная низкая струна;
- нужен другой строй → отдельный инструмент под строй;
- нужен выборный бас → баян / аккордеон free-bass;
- нужна полупедаль → цифровое пианино;
- нужен квартвентиль → переходный тромбон;
- нужны открытые клапаны → флейта / YFL-372;
- нужна двойная валторна → переход F → F/B♭;
- нужен больший клавишный диапазон → stage / MIDI;
- нужен cutaway → акустическая гитара с вырезом;
- нужна короткая мензура → bass short-scale / малая электрогитара;
- нужен компактный корпус → compact acoustic / digital piano;
- нужен отдельный строй → отдельная акустическая или электрическая гитара;
- нужна дополнительная педаль → piano pedal work / organ coordination.
