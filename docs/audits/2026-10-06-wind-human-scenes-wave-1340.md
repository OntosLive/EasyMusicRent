## Предварительная проверка до публикации

До перевода в `main`:

- все 64 будущих slug отдельно проверены по текущему репозиторию;
- точных существующих адресов среди 64 не найдено;
- четыре новых JSON-файла разбираются;
- количество: 16 + 16 + 16 + 16 = 64;
- все 64 slug уникальны внутри волны;
- у каждой записи есть предметный родитель;
- у каждой записи есть `search_title`, `editorial_title`, `description`, три смысловых блока и итоговый вопрос;
- все внутренние ссылки имеют корректную адресную форму.

## Содержательный результат

Волна переводит духовые из структуры «семейство → модели» в сеть переходов между реальными исполнительскими состояниями:

**первый инструмент → домашняя практика → возврат → смена системы / голоса → ансамблевая функция → проба перед покупкой**.

Для редких инструментов временный доступ особенно естественен: пикколо, alto/bass flute, A/E♭ clarinet, bass clarinet, soprano/baritone sax, English horn, oboe d’amore, contrabassoon, bass trombone и sousaphone могут требоваться по конкретной партитуре или проекту без необходимости постоянного владения.
