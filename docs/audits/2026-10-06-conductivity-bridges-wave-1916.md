## Как выбирались страницы

Первая волна намеренно взяла самые крупные и тонкие кластеры.

### Casio

Пять модельных страниц получили выходы не только назад в бренд/цифровое пианино, но и к реальным решениям:

- компактность комнаты;
- сравнение механик;
- работа над педалью;
- MIDI;
- работа над динамикой;
- проба перед покупкой.

### Легендарные синтезаторы

Korg M1, Roland D-50, JUPITER-8, Prophet-5 и Yamaha DX7 связаны с:

- hardware ↔ software сравнением;
- sound design;
- real-time modulation;
- пробой синтезатора перед покупкой.

Легендарная модель перестаёт быть музейным тупиком и возвращается в живую функцию.

### Рояли

Пятнадцать тонких страниц получили переходы между:

- конкретными концертными моделями;
- репетицией;
- конкурсом;
- камерным концертом;
- студийной записью;
- сравнением вертикального пианино и рояля по исполнительской функции.

### Виолончель

Двадцать страниц происхождения, брендов, учебных серий и общих классов связаны с:

- сменой размера;
- домашней учебной практикой;
- камерным ансамблем;
- прослушиванием;
- пробой перед покупкой;
- студийной записью.

### Контрабас

Девятнадцать страниц связаны с:

- сравнением мензур;
- сменой размера;
- arco;
- камерной работой;
- переходом с бас-гитары или виолончели;
- выбором постоянного инструмента;
- ростом и размером руки.

## Ожидаемый эффект

Поскольку все 64 выбранные страницы были диагностированы как тонкие листья с нулевой боковой степенью, а каждому добавлено по два новых неструктурных перехода, ожидаемая метрика после успешной сборки:

| Метрика | До | Ожидается после |
| --- | ---: | ---: |
| Темы | 1916 | 1916 |
| Боковые рёбра | 1805 | 1933 |
| Все рёбра | 5605 | 5733 |
| Страницы с боковым маршрутом | 901 | 965 |
| Покрытие боковыми маршрутами | 47,03% | ≈50,37% |
| Страницы только с вертикальной навигацией | 1015 | 951 |
| Листья с боковым маршрутом | 842 | 906 |
| Тонкие листья | 859 | 795 |

Фактические значения измеряются повторным графовым аудитом после зелёной публикации.

## Архитектурный смысл

Раньше рост выглядел так:

**новый различимый запрос → новая страница → родитель → фонд**.

Теперь появляется вторая операция:

**существующая страница → ближайшее осмысленное различение → соседняя сцена / критерий / переход → продолжение движения**.

Это соответствует исходной формуле проекта:

**контекст не равен сумме документов; контекст — восстановленная траектория между ними.**

Для ONTOS.RENT это означает:

**каталог становится фондом не тогда, когда в нём много страниц, а когда человек может продолжать различение без возврата каждый раз в корень.**

## Следующий шаг

После публикации:

1. повторно измерить граф тем же методом;
2. подтвердить фактическое пересечение отметки 50% бокового покрытия;

4. следующую мостовую волну направить не в те же семейства, а туда, где остаётся максимальная доля тонких листьев: блокфлейта, фагот, органы, гитарный backline, Orff, редкие/исторические семейства или другие узлы по свежему рейтингу.
