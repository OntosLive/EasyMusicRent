- взрослая акустическая гитара → первые аккорды / проба перед покупкой;

- синтезатор для live → быстрые переключения / импровизация;
- смычковые на гастроли → гастрольный камерный состав / замена участника;
- готово-выборный баян на конкурс → конкурсная программа / переход на выборный бас.

## Архитектурный результат

После wave 10 вопрос «куда ведёт модель?» был закрыт полностью.

Wave 11 начинает следующий слой:

**куда ведёт уже сформулированная человеческая задача?**

То есть сеть перестаёт быть только:

**модель → сцена**

и становится:

**сцена → соседняя сцена → техническое различение → следующий выбор**.

Следующие bridge-волны нужно выбирать из фактических немодельных тонких листьев release artifact, сохраняя приоритет страниц с высокой человеческой полезностью.
