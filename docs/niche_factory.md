# ONTOS. Фабрика ниш (пилот переносимого ядра)

## Зачем этот модуль

Не «сто копий ONTOS.RENT». Производственная цепь **человеческая ситуация → профессиональное различение → реальный исполнитель → прямой контакт → сделка → обратная связь**.

Существующий scripts/site_core.py не изменён: он связан с 1 980 музыкальными темами, двумя публичными слоями, оформлением и конкретным фондом. Сначала проверяем независимый переносимый модуль, затем переносим подтверждённые общие части, не разрушая исходный проект.

## Что работает сейчас

- Реестр 100 ниш с ситуацией клиента и гипотетической экономической схемой, data/niche_factory/100_hypotheses.csv.
- Детерминированная предварительная сортировка по пяти субъективным осям. Она не измеряет спрос, маржу или фактическую готовность исполнителя.
- Получение задания для модели по одной выбранной нише. Задание требует самостоятельно различающихся сцен и запрещает придумывать факты.
- Независимый статический компилятор, читающий проверенную конфигурацию. Он выпускает главную и отдельные предметные ситуации с прямым телефоном и мессенджерами, без заявок, кабинетов, регистрации, корзины и платежей.
- Проверка публикационных допусков: executor_verified, contact_verified, offer_reviewed, legal_reviewed.
- Без этих допусков возможен только закрытый черновик: noindex, robots.txt: Disallow, без sitemap.
- Для опубликованной версии создаются self-canonical, sitemap.xml, robots.txt и отдельная страница о данных. Допуск не означает автоматическую загрузку сайта в интернет.
- Защита от повторных путей, повторных сцен и записи поверх уже созданного набора файлов.

## Воспроизведение

Запуск из корня репозитория, Python 3.12, только стандартная библиотека:

- python -m unittest discover -s tests -p test_ontos_factory.py -v
- PYTHONPATH=tools python -m ontos_factory.cli top --data data/niche_factory/100_hypotheses.csv --expected-count 100 --output _audit/niche-top10.md
- PYTHONPATH=tools python -m ontos_factory.cli brief --data data/niche_factory/100_hypotheses.csv --id N001 --output _audit/brief-N001.md
- PYTHONPATH=tools python -m ontos_factory.cli build --config tools/ontos_factory/sample_contrabass_repair.json --output _audit/demo-contrabass

Для локального предпросмотра: python -m http.server 8000 -d _audit/demo-contrabass . Домен example.invalid намеренно не подходит для публичного выпуска.

## Как появляется самостоятельная ниша

1. Ниша выбирается по реальной человеческой ситуации, а не по высокочастотному слову.
2. Подтверждаются умение и готовность исполнителя. Согласуются процесс принятия заказа, ответственность и возможное вознаграждение.
3. Модель помогает развернуть действительные различения в оригинальные содержательные страницы, владелец проверяет формулировки и факты.
4. Первоначальная страница ведёт к прямому звонку или сообщению, а не скрытому лидогенератору.
5. Только после проверки домена, правового слоя, контактов и исполнителя возможна отдельная публикация.
6. Каждый контакт регистрируется на уровне намерения и результата: тема, источник, подходящий исполнитель, реальная сделка, трудозатраты, полученное вознаграждение.

## Ограничения масштаба

- 100 гипотез не равны 100 подтверждённым рынкам или сайтам. Выпустить десять реально разных полезных сервисов лучше, чем сто одинаковых страниц с разными словами.
- Недопустимы ложное наличие, придуманная квалификация, вымышленные отзывы, сертификаты, сроки и гарантии.
- Разные домены с идентичными услугами и одинаковыми страницами рискуют стать doorway abuse в терминологии Google; автоматически размножать сайты ради захвата запросов нельзя. См. https://developers.google.com/search/docs/essentials/spam-policies .
- Нельзя обещать, что исполнитель выполнит заказ, пока нет его подтверждения. Комиссия не возникает автоматически из факта передачи телефона; нужна явная договорённость.
- Для магазина без корзины требуются реальные ассортимент и цены либо честный каталог на подбор. Каталог запросов нельзя выдавать за подтверждённый склад.
- Этот модуль пока не создаёт домены, не меняет DNS, не публикует в GitHub Pages, не размещает трекеры, не обрабатывает заказы и не заменяет предметную редактуру. Это работоспособная фабрика черновиков и статических страниц.
