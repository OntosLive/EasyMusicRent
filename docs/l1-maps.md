# Карты L1: история отдельного слоя N.2

**Статус: историческое решение, отменённое для публичной архитектуры.** Содержательные направления этих карт сохранены внутри N.1. Действующий порядок: N.0 → N.1 → дочерняя сущность; см. [активный канон](active-canon-2026-10-04.md) и [отказ от отдельного N.2](n2-retirement.md).

На прежнем этапе для двенадцати верхних семейств были созданы отдельные карты:

- /klavishnye/karta/ — Клавишные инструменты
- /smychkovye/karta/ — Смычковые инструменты
- /gitary/karta/ — Гитары
- /shchipkovye/karta/ — Щипковые струнные
- /arfy-liry/karta/ — Арфы и лиры
- /duhovye/karta/ — Духовые инструменты
- /udarnye/karta/ — Ударные и перкуссия
- /bayan-akkordeon/karta/ — Баян, аккордеон и гармонь
- /elektronnye/karta/ — Электронные музыкальные инструменты
- /traditsionnye/karta/ — Народные и традиционные музыкальные инструменты
- /istoricheskie/karta/ — Исторические музыкальные инструменты
- /redkie-eksperimentalnye/karta/ — Редкие и необычные музыкальные инструменты

Тогда карты могли быть частично пустыми: пустой узел обозначал отсутствие опубликованной дочерней страницы, а не отсутствие места в архитектуре. Это описание прежнего этапа, а не указание создавать пустые публичные экраны при продолжении.

Прежняя схема:

- N.0 = `/<slug>/`;
- N.1 = `/details/<slug>/`;
- N.2 = `/<slug>/karta/`.

Сейчас сборщик использует сохранённые исходники карт для навигации и выводит по старым адресам HTML-переадресацию на `/details/<slug>/`, при наличии дочерних направлений — на `#razdely`. Отдельные N.2 и новые публичные ссылки на `/karta/` не создаются.
