# Полный редакционный проход поисковых заголовков ONTOS.RENT

Дата запуска: 9 октября 2026.

## Объём, без округлений

- **1 980 самостоятельных тем**.
- **3 960 разных индексируемых страниц**: N.0 и N.1 одной темы не дублируют редакционную функцию.
- **8 страниц условий**: отдельная редакционная очередь после предметного корпуса.
- **3 968 действующих HTML-документов** со своими тегами `<title>`.
- **78 технических перенаправлений** не относятся к заголовкам для поиска.

Количество страниц не равно количеству готовых авторских решений. Любые расчёты заполненности обязаны отличать тему, заголовок и технический адрес.

## Операционный маршрут

1. Восстановить точный источник темы из `_audit/build.json` и файла содержания.
2. Различить намерение для N.0 (получить временный доступ) и N.1 (разобраться в предмете).
3. Выявить **конкретное условие решения**. Проверять, позволяет ли оно задать более точный вопрос, выбрать конфигурацию, сравнить альтернативы или назначить нужную проверку.
4. Написать два самостоятельных заголовка моделью. Нельзя использовать Python для написания или перефразирования правой части.
5. Зафиксировать для каждого роль, источник, цитату из текста, практическую развилку и результат следующего шага в `content/title-editorial-evidence.json`.
6. Добавить **полную** строку в `content/authored-title-responses.json`.
7. Проверить независимость N.0/N.1, отсутствие выдуманных обстоятельств, ложной доступности, механического повтора, дублей и шаблонной «компетентности».
8. Запустить сборку и обе проверки. Нельзя выдавать синтаксический CI за доказательство смысловой точности.

## Реестр всех страниц

`scripts/title_worklist.py` по результату каждой сборки составляет:
- `_audit/title-worklist.json`;
- `_audit/title-worklist.csv` (UTF-8 BOM для работы в Excel).

Оба файла включены в release audit; генератор **не создаёт текст заголовков**, а только показывает фактическую публикацию, источник и статус ручной смысловой работы по каждому адресу.

Состояния: `pending_functional_review` и `model_reviewed_pilot`. До пользовательской проверки пилот не называется утверждённым владельцем. Текст в поисковой выдаче может отличаться от HTML `<title>`, и это отдельный показатель.

## Первый предметный пакет

Первые восемь тем выбраны из уже замеченных поисковых показов и учебных ситуаций: концертный контрабас, скрипка на месяц, контрабас 4/4, временные замены на время ремонта, скрипка для конкурса, учебный год и пианино для музыкальной школы.

Задачи действительно различаются:
- для концерта — параметры исполнителя и время на площадке;
- для инструмента 4/4 — проверка фактической мензуры, а не ярлыка корпуса;
- для конкурса — срок на привыкание и проверка отклика на программе;
- для годового обучения — возможность изменения размера;
- для школьного пианино — учебная функция до необратимой покупки.

Следующий пакет выбирается из текущих поисковых показов, базовых семей и новых самостоятельных сцен. Не писать формально весь корпус одним типовым окончанием.
