Виолончель существует между инструментом, стулом и телом

Для виолончели размер сам по себе ничего не заканчивает. Шпиль, высота стула, ширина корпуса, длина струны и доступ к грифу собираются в одну исполнительскую геометрию.

Фонд различает не только модели, а способы, которыми конкретная виолончель входит в конкретное тело и конкретную работу.

  1. 01Виолончель для начала, пока собственная посадка ещё только появляется
  2. 02Виолончель ребёнку на тот размер, который нужен именно сейчас
  3. 03Виолончель 1/4, когда четвертушка нужна ровно на один этап роста
  4. 04Виолончель 1/2, пока половинный размер действительно совпадает с телом
  5. 05Виолончель 3/4, когда до полного размера уже близко, а спешить всё ещё незачем
  6. 06Виолончель 7/8, когда полный звук нужен без лишней геометрии 4/4
  7. 07Виолончель 4/4, когда полный размер ещё должен совпасть с конкретным телом
  8. 08Удобная виолончель, когда инструмент, стул и тело должны собраться в одну систему
  9. 09Ученическая виолончель, когда инструмент должен помогать строить навык
  10. 10Профессиональная виолончель, когда требования задаёт уже реальная работа
  11. 11Сольная виолончель, когда инструмент должен выдержать внимание без оркестровой тени
  12. 12Виолончель для оркестра, когда личный инструмент должен войти в общую ткань
  13. 13Виолончель на время ремонта, чтобы расписание не зависело от мастерской
  14. 14Виолончель для невысокого роста, когда полный размер не должен диктовать посадку
  15. 15Виолончель для небольшой руки, когда расстояния должны оставаться музыкальными, а не силовыми
  16. 16Виолончель на экзамен, когда чужой инструмент должен перестать быть чужим заранее
