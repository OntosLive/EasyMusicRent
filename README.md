# COMPASS.RENT

**Газета аренды. Сегодня утюг. Завтра что угодно.**

COMPASS.RENT не является каталогом, маркетплейсом или витриной категорий.

Предмет меняется. Печатная машина остаётся.

> Есть вещь → есть сцена → есть выпуск → есть адрес.

## Формула

**предмет → заголовок → три колонки → три удара → формула → контакт**

Никакой новой архитектуры под каждую категорию.

Пианино, утюг, проектор, контрабас, генератор, чемодан или стол проходят через одну и ту же форму.

## Принцип

Не строить магазин вокруг каждого предмета.

Достаточно сообщить:

- что есть;
- зачем это может понадобиться;
- что с этим можно сделать;
- как связаться.

## Техническая машина

- HTML
- CSS
- Markdown-выпуски
- Git
- GitHub Pages
- архив постоянных адресов

## Нулевой закон

> **Только так и ничего иначе.**

Форма остаётся. Меняется только предмет и текст выпуска.
