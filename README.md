# EASYMUSIC.RENT

Газета аренды музыкальных инструментов.

Не интернет-магазин. Не воронка. Не каталог ради каталога.

Каждый выпуск — отдельная сцена, объявление или различение, получающее постоянный адрес.

## Машина публикации

**Markdown → GitHub Pages → постоянный URL → архив**

- `/` — текущий выпуск
- `/archive/` — подшивка
- `/archive/001/` и далее — постоянные адреса выпусков
- `issues/*.md` — источник истины

## Канон

> Сначала функция. Потом инфраструктура.

Если смысл проходит текстом, интерфейс считается завершённым.
